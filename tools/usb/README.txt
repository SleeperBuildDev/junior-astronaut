JUNIOR ASTRONAUT: Lunar Survival Mission  (version 1.0, offline copy)
=====================================================================

HOW TO PLAY (Windows 10 / 11)
  1. Copy this whole folder to the computer (keep the files together).
  2. Double-click  "Play Junior Astronaut.bat".
  3. The game opens in your web browser. Keep the small black window open
     while you play; close it when you are done.

  No internet and no installs are needed. Use Google Chrome or Microsoft Edge
  for the best result. If Windows shows "Windows protected your PC", click
  "More info" -> "Run anyway" (the launcher only starts a local web server
  for the game on this computer).

  Don't open game\index.html directly: browsers block a 3D game that is
  opened straight from a file, which is why the launcher is there.

CONTROLS
  Mouse - look around (click the game to capture the mouse, Esc frees it)
  W A S D - walk     Shift - run     Space - jump
  E - use / scan (hold E for repairs)     F - helmet lamp
  K - Knowledge Center     C - crew panel     T - settlement panel (Mission 9)     Esc - pause
  Enter - close knowledge cards

  Settings -> Graphics: choose Low / Medium / High for the computer's speed.
  Settings -> Language: English or Burmese.

SAVES
  Progress is saved in the browser on each computer, so a new computer
  starts from Mission 1. (Settings and saves stay on that computer.)

ON A MAC OR LINUX
  Open a terminal in the "game" folder and run:  python3 -m http.server 8765
  then open http://localhost:8765 in the browser.
